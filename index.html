How it works

Private by design

There's no server. Your logins and playlists go straight between your browser and each music service.

Smart matching

Songs are matched by recording ID (ISRC) when possible. Otherwise titles are cleaned up, removing tags like "(Official Video)".

You stay in control

Check every match before transferring. Re-runs skip songs that are already in the destination playlist.

How to get it (needs an Apple Developer account)
  1. In Identifiers, create a Media ID with MusicKit enabled.
  2. In Keys, create a key with Media Services (MusicKit) and download the .p8 file.
  3. Fill in the fields below and click Generate. The token lasts about 6 months. Your key file is only used for this step and is never saved.
